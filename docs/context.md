# 领域用语

| 用语 | 含义 |
| --- | --- |
| 项目（Project） | 一款游戏的一组翻译工作，共享源语言和资源约定。 |
| 源语言（Source language） | 所翻译原文的语言。 |
| 目标语言（Target locale） | 一套独立交付的本地化译文，可区分文字体系和地区。 |
| 原文快照（Source snapshot） | 一次完整或部分获取后保存的游戏资料。 |
| 资源（Resource） | 适配器提取的原文及其真实上下文，例如一段剧情或某个表字段；指向一个交付字典位置。 |
| 原文出现（Occurrence） | 原文在资源中的一次出现；重复出现保留阅读顺序和语境。 |
| 字典位置（Dictionary location） | 译文交付文件及其嵌套路径；最后一级为精确原文到译文。 |
| 待译键（Translation task） | 一个字典位置中的一条缺失原文；同位置重复原文只需一份译文。 |
| 翻译计划（Translation plan） | 本次选中的待译键，以及对应的原文资源。 |
| 标准术语（Canonical term） | 从 names 等指定字典或术语表确定的约定译法。 |
| 已接受译文（Accepted translation） | 通过任务约束、已保存但尚未发布的译文。 |
| 发布（Publication） | 将通过检查的译文作为一次可识别的更新交付使用。 |
