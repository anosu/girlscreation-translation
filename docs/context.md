# 领域用语

| 用语 | 含义 |
| --- | --- |
| 项目（Project） | 一款游戏的一组翻译工作，共享源语言和资源约定。 |
| 源语言（Source language） | 所翻译原文的语言。 |
| 目标语言（Target locale） | 一套独立交付的本地化译文，可区分文字体系和地区。 |
| 原文快照（Source snapshot） | 一次完整或部分获取后保存的游戏资料。 |
| 原文清单（Source catalog） | 从快照提取、供各目标语言共享的文本条目、上下文及初始发布映射。 |
| 文本条目（Text entry） | 在明确场景中需要确定一份译文的原文；同文异境可分成不同条目。 |
| 文本分类（Category） | 按用途划分的文本种类，例如名称、剧情、主数据。 |
| 上下文组（Context group） | 适合一起理解的条目集合，例如一段剧情。 |
| 发布位置（Output binding） | 客户端查找译文的位置；一个条目可对应多个位置。 |
| 术语（Term） | 在指定项目、目标语言和适用范围内具有约定译法的名称或表达。 |
| 术语表（Glossary） | 术语的译法、别名、适用范围和说明。 |
| 术语提案（Term proposal） | 附有原文出处和解释、等待校验的术语增补建议。 |
| 翻译任务（Translation task） | 针对特定原文版本和目标语言确定译文的工作。 |
| 翻译计划（Translation plan） | 一次更新选中的任务及其依据。 |
| 已接受译文（Accepted translation） | 通过当前任务约束、可供后续工作使用的译文，尚未发布。 |
| 发布（Publication） | 将通过检查的译文作为一次可识别的更新交付使用。 |
