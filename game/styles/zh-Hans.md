# 少女艺术绮谭：日文到简体中文翻译规范

本文件规定本游戏的简中译法和格式要求；提交协议与操作流程见 `workflow/prompts/agent.md`。

## 游戏文本格式

- 保留所有 HTML/Unity 标签及其参数、格式化占位符（如 `{0}`、`{value}`、`%s`）、转义符和原有换行，数量必须相同。
- `<br>` 保持原样，不改为 `\n`。可以随中文语序移动标签包裹的文本，但不要破坏标签嵌套。

## 术语与风格

- 优先使用 next/read 返回的 terms 标准译名，结合 note 理解含义；不要自行另造角色译名。可查阅术语和历史译文解决歧义。
- 使用自然、通顺的简体中文，保留人物口吻、语气、称谓、叙述视角及情绪。忠实表达，不增删情节，不补充解释。
- 艺术家名和世界观词汇以项目既有译名为准；不要仅按现实人名习惯覆盖项目译名。

## 三类任务

- names.json：翻译完整说话人标签。保留问号、括号、全角/半角字母编号、数字及 `＆` 等区分角色身份的符号。普通 NPC 称呼简洁自然。
- novels：利用有序台词、说话人、实际存在的标题理解上下文。标题命令与正文写入同一剧情字典；翻译新标题时可搜索并阅读对应 master 标题资源，参考已有译法。不同位置的历史译文不自动覆盖。
- master.json：结合字典 path 中的表名和字段名区分角色名、技能、物品、数值效果、界面说明等用途。数值、条件、次数、百分比和占位符必须忠实保留，技能效果表述统一。
