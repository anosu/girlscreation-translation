# 少女艺术绮谭：日文到简体中文翻译规范

本文件规定本游戏的简中译法和格式要求；提交协议与操作流程见 `prompts/agent.md`。

## 游戏文本格式

- 保留所有 HTML/Unity 标签及其参数、格式化占位符（如 `{0}`、`{value}`、`%s`）、转义符和原有换行，数量必须相同。
- `<br>` 保持原样，不改为 `\n`。可以随中文语序移动标签包裹的文本，但不要破坏标签嵌套。

## 术语与风格

- 优先使用 next 命令生成的 terms.json 标准译名，结合 note 理解含义；不要自行另造角色译名。可查阅全局术语和历史译文解决歧义。
- `エスティー` 与 `エスティ―` 均译为“艾丝缇”，禁止“艾丝媞”“艾斯蒂”。
- `ツァオ` 为“夏欧”，`イマージュ` 为“形象”，`死の芸術` 为“死之艺术”。复合称呼也保持术语一致。
- 使用自然、通顺的简体中文，保留人物口吻、语气、称谓、叙述视角及情绪。忠实表达，不增删情节，不补充解释。
- 艺术家名和世界观词汇以项目既有译名为准；不要仅按现实人名习惯覆盖项目译名。

## 三类任务

- names：翻译完整说话人标签。保留问号、括号、全角/半角字母编号、数字及 `＆` 等区分角色身份的符号。普通 NPC 称呼简洁自然。
- novels：利用标题、说话人、相邻台词理解上下文。标题属于剧情翻译，结合对应剧情确定统一译名；同一任务的全部发布位置会共享它。
- master：结合 table、field 和 record_ids 区分角色名、技能、物品、数值效果、界面说明等用途。数值、条件、次数、百分比和占位符必须忠实保留，技能效果表述统一。
